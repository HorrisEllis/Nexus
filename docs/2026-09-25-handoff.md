From a session without NEXUS running: `versionium/lib/engine.js` `commit({ message, system, causedBy })` in the extracted tree (how 0.39.248–250 were recorded). Put the commit id in the spec entry and the changelog.
4. **Git:** commit every release; never leave a delivered zip uncommitted (241–247 were).

## The map for the rest (in order)

### 1. Element picker assigns selectors (fixes ChatGPT without guessing)
- **Exists:** Clear Glass Element Picker (☰ → Tools → Element Picker). Flow: `clear-glass/src/preload/index.js:19` `dom.pick` → `ipcMain 'dom:pick'` → `clear-glass/src/dom/archaeology.js` `handlePick({ agentId, nodeId, meta, name })` (registers the pick as a named hook); the result comes back on `dom:pick-result` (`clear-glass/renderer/browser.js:640–764`).
- **Exists (0.39.249):** `POST :7820/api/agents/:id/selectors { selectors: { resp|input|send }, source: 'picker', evidence: { url, matched, text } }` — refused without evidence; pushed to every open tab of that provider.
- **Build:** when a pick is made on a provider page (URL host matches a provider in `guardian/lib/agent-registry.seed.json`), offer *"This is <provider>'s reply / input / send button"*. Generate a stable selector for the node (prefer `data-*` attributes and roles over classes); **check it on the same page** (`querySelectorAll` → matched count, last match's text length; for `resp` the last match must hold the latest answer's text); POST with that evidence.
