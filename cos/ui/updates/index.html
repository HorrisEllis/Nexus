Updates

What GitHub has that this Nexus does not, system by system. An update is backed up first, then each changed system restarts by itself; Clear Glass waits for you. Every one is kept below, and the last can be rolled back.

Update settings

Automatic updatesAuto brings every update in by itself when Nexus is idle (backed up first). Notify only tells you, in the bell. Off checks nothing.

Your own commitsWhen this folder has commits GitHub lacks: Auto keeps them on a branch (local/<date>) and updates, when GitHub already has the same changes. Ask waits for you to press Keep mine and update.

COS's own app (the exe) has its own update setting, in its tray menu: it is not Nexus, and updates separately.
