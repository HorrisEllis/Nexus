Constitutional Laws
These laws are enforced at the kernel level. They cannot be toggled.
Violation is structurally impossible — the kernel design makes direct calls impossible.
Enforced Laws
Law I
Local First
Ollama orchestrates. Cloud agents are external sensors. All reasoning happens locally before anything touches the internet.
ENFORCED — cannot be bypassed
Law II
Event Authority
No state changes directly. Only events. Every state transition is an immutable event on the bus. The entire history is replayable from seq:0.
ENFORCED — StreamLog captures everything
Law III
Layer Sovereignty
Each layer has exactly one job. No module calls another module directly. All communication via kernel.emit() only.
ENFORCED — kernel design makes direct calls impossible
Law IV
Schema Over Code
Behavior emerges from schemas not conditionals. Plugins declare capabilities. The runtime composes them.
ENFORCED — manifest is schema-constrained, temp:0
